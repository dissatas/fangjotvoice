# ฟังจด — แอป Android บันทึก ถอดเสียง และสรุปประชุม

แอป Android (Capacitor 7) ที่วางเครื่องไว้กลางโต๊ะแล้วถอดเสียงประชุมไทย/อังกฤษสด แยกผู้พูด สรุปประชุมพร้อมรายการงาน และส่งออก PDF / Word / Markdown

## ความสามารถ
- ถอดเสียงสดด้วยบริการรู้จำเสียงของ Android (ไทย `th-TH` หรือ English) รองรับคำทับศัพท์ ระบุภาษาแต่ละช่วง TH / EN / TH+EN
- แยกผู้พูด: แตะชื่อผู้พูดระหว่างประชุม หรือให้ AI จัดผู้พูดใหม่จากบริบท
- สรุปด้วย AI (Claude API): ภาพรวม มติ และตาราง "ใคร ทำอะไร ส่งเมื่อไหร่" แก้ไขได้ทุกช่อง
- ส่งออก PDF, Word (.docx), Markdown, .txt แล้วแชร์ผ่าน LINE / Gmail / Drive ด้วยเมนูแชร์ของเครื่อง
- **ทำงานเบื้องหลัง:** ปิดจอหรือสลับไปแอปอื่นได้ แอปยังฟังและถอดเสียงต่อผ่าน foreground service (มีแถบแจ้งเตือน "ฟังจดกำลังบันทึกประชุม" พร้อมปุ่มหยุด)
- ทำงานออฟไลน์ได้ (ฟอนต์และไลบรารีฝังในแอป) เก็บข้อมูลไว้ในเครื่อง หน้าจอเปิดค้างระหว่างบันทึก
- ต้องใช้อินเทอร์เน็ตเฉพาะตอนสรุปด้วย AI (และตอนถอดเสียง ถ้าเครื่องไม่มีโมเดลภาษาไทยแบบออฟไลน์)

## สร้างไฟล์ APK

### วิธีที่ 1 — GitHub Actions (ไม่ต้องติดตั้งอะไร)
1. push โฟลเดอร์นี้ขึ้น GitHub repo (branch `main`)
2. เปิดแท็บ **Actions** → รอ workflow **Build Android APK** เสร็จ (~5–8 นาที)
3. ดาวน์โหลด `fangjot-apk` → ได้ `fangjot-debug.apk`
4. ถ้า push tag เช่น `v1.0.0` ระบบจะสร้างหน้า **Releases** พร้อมไฟล์ APK ให้ดาวน์โหลดตรงจากมือถือ

ต้องการ APK แบบ release ที่เซ็นด้วย key ขององค์กร: ใส่ secrets `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD` ใน repo

### วิธีที่ 2 — Android Studio
```bash
npm install
npm run sync        # คัดลอกฟอนต์/ไลบรารี + bundle + cap sync
npx cap open android   # เปิดใน Android Studio แล้วกด Run
```
ต้องใช้ Node 20+, JDK 21, Android SDK 35

## ติดตั้งบนมือถือ
เปิดไฟล์ APK บนเครื่อง → อนุญาต "ติดตั้งแอปที่ไม่รู้จัก" ให้เบราว์เซอร์/ไฟล์ → ติดตั้ง → ครั้งแรกที่กดบันทึกจะขอสิทธิ์ไมโครโฟน
สำหรับองค์กร: ส่งต่อผ่าน MDM ได้ (Intune / Comodo ITSM)

## ข้อจำกัดที่ควรรู้
- Android จะตัดการฟังเมื่อเงียบสักพัก บริการเบื้องหลังจะต่อการฟังให้อัตโนมัติ บางเครื่องจะมีเสียง "ติ๊ง" ตอนเริ่มฟังใหม่ และอาจหลุดคำในช่วงต่อประมาณ 1 วินาที
- มือถือบางยี่ห้อ (Xiaomi, OPPO, vivo, Huawei) ปิดแอปเบื้องหลังแรงกว่าปกติ ให้ตั้งค่าแบตเตอรี่ของฟังจดเป็น "ไม่จำกัด"
- ระหว่างถอดเสียงจะเก็บไฟล์เสียงพร้อมกันไม่ได้ เพราะ Android ให้แอปเดียวใช้ไมค์
- การแยกผู้พูดอัตโนมัติจากลักษณะเสียง (diarization) ต้องมีเซิร์ฟเวอร์ประมวลผล เช่น Whisper + pyannote บน GPU ภายในองค์กร
- แอปเก็บข้อมูลในเครื่อง ถ้าลบแอป ข้อมูลจะหายไปด้วย ควรส่งออกการประชุมสำคัญเก็บไว้

## โครงสร้าง
```
www/index.html          หน้าจอแอปทั้งหมด (HTML/CSS/JS ไฟล์เดียว)
src/native.js           เชื่อมปลั๊กอิน Android (บันทึกเบื้องหลัง ไฟล์ แชร์ จอเปิดค้าง ปุ่ม back)
android/app/src/main/java/com/fangjot/app/RecorderService.java   บริการบันทึกเบื้องหลัง
scripts-build.sh        คัดลอกฟอนต์/ไลบรารีลง www และ bundle native.js
android/                โปรเจกต์ Android ที่ Capacitor สร้าง
.github/workflows/      สคริปต์ build APK บน GitHub
```
